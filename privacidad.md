# Política de Privacidad de RentApp Conductores

Última actualización: 23 de septiembre de 2026

Esta Política de Privacidad explica cómo RentApp Conductores ("la Aplicación") recopila, utiliza, almacena y protege la información cuando usted utiliza nuestro software.

La Aplicación es operada desde San Miguel de Tucumán, Argentina.

Si tiene alguna pregunta sobre esta Política de Privacidad o sobre el tratamiento de sus datos personales, puede contactarnos a través del correo electrónico: [oficialrentapp@gmail.com](mailto:oficialrentapp@gmail.com).

### 1. Información que recopilamos y procesamos

Dependiendo de cómo interactúe con RentApp Conductores, podemos recopilar o procesar las siguientes categorías de información:

- **Información de la cuenta:** Utilizamos su dirección de correo electrónico y el identificador de usuario proporcionado por Firebase Authentication para crear, identificar y gestionar su cuenta de RentApp.

- **Identificador del dispositivo (Android ID):** La Aplicación utiliza el identificador Android ID proporcionado por el sistema operativo Android. Este identificador se utiliza para controlar qué dispositivo está autorizado para utilizar una cuenta, gestionar la elegibilidad para períodos de prueba gratuitos, prevenir el abuso mediante la creación repetida de cuentas y reforzar la seguridad del servicio.

- **Información de suscripción:** Podemos procesar información relacionada con su suscripción a RentApp Premium, incluyendo el estado de la suscripción, el producto y plan contratado, fechas relacionadas con la vigencia de la suscripción y los identificadores técnicos de compra proporcionados por Google Play Billing.

- **Purchase Token:** Google Play puede proporcionar a la Aplicación un identificador técnico denominado purchase token asociado a una compra o suscripción. RentApp utiliza este identificador para verificar la validez de la suscripción con Google Play y evitar que una misma compra sea utilizada indebidamente por diferentes cuentas. RentApp no recibe ni almacena directamente los datos de su tarjeta de crédito o medio de pago.

- **Información técnica necesaria para el funcionamiento:** La Aplicación puede procesar información técnica necesaria para ejecutar sus funciones, diagnosticar errores mediante registros técnicos locales o del servidor y proteger el funcionamiento del servicio. RentApp no utiliza actualmente servicios de analítica publicitaria ni Firebase Analytics o Firebase Crashlytics.

- **Datos visibles en pantalla mediante MediaProjection:** Para proporcionar el cálculo de rentabilidad en tiempo real, RentApp puede solicitar autorización para capturar temporalmente el contenido visible en la pantalla del dispositivo mediante la función MediaProjection de Android.

  Esta captura se utiliza para reconocer mediante OCR información visible en las ofertas de viaje, como precios, distancias y tiempos.

  **La información capturada mediante MediaProjection y las imágenes de pantalla utilizadas por el sistema OCR se procesan localmente en el dispositivo. RentApp no guarda estas imágenes en sus servidores ni las transmite a servidores de RentApp para realizar el reconocimiento.**

  La captura de pantalla solamente comienza después de que el usuario concede expresamente el permiso correspondiente de Android y finaliza cuando RentApp o el propio sistema Android terminan la sesión de captura.

- **Datos locales de uso:** Algunas funciones de RentApp, como el historial de turnos, mantenimiento, precios configurados y determinadas preferencias de la Aplicación, pueden almacenarse localmente en el dispositivo.

- **Comunicaciones de soporte:** Podemos recibir y conservar la información que usted nos proporcione voluntariamente cuando se comunique con nosotros para solicitar asistencia técnica, realizar consultas o informar problemas.

### 2. Cómo utilizamos la información

La información recopilada o procesada por RentApp se utiliza para:

- Crear, identificar y autenticar su cuenta.
- Autorizar el uso de una cuenta en un dispositivo determinado.
- Proporcionar las funciones principales de RentApp.
- Procesar localmente las ofertas de viaje mostradas en pantalla.
- Gestionar el acceso a RentApp Premium.
- Verificar suscripciones mediante Google Play.
- Detectar si una suscripción continúa activa.
- Evitar que una misma compra sea reutilizada por diferentes cuentas.
- Controlar la elegibilidad para períodos de prueba gratuitos.
- Evitar el abuso del sistema mediante la creación repetida de cuentas.
- Mantener la seguridad e integridad del servicio.
- Diagnosticar problemas técnicos.
- Responder a solicitudes de soporte.
- Cumplir obligaciones legales cuando corresponda.

### 3. Servicios de terceros

RentApp utiliza determinados servicios proporcionados por Google para poder operar.

Estos servicios incluyen:

- **Google Play Billing:** Utilizado para gestionar las suscripciones a RentApp Premium y obtener la información necesaria para verificar el estado de una compra o suscripción.

- **Google Play Developer API:** Utilizada por los servidores de RentApp para verificar el estado real de las suscripciones.

- **Firebase Authentication:** Utilizado para autenticar e identificar las cuentas de los usuarios.

- **Cloud Firestore:** Utilizado para almacenar información necesaria para gestionar las cuentas, el acceso Premium, los dispositivos autorizados y los mecanismos de prevención de fraude.

- **Firebase Cloud Functions:** Utilizado para ejecutar de forma segura determinadas verificaciones en el servidor, incluyendo la validación de suscripciones, autorización de dispositivos y eliminación de cuentas.

- **Google ML Kit / reconocimiento de texto:** Utilizado para realizar reconocimiento óptico de caracteres (OCR) sobre la información visible en pantalla necesaria para las funciones de RentApp. El procesamiento de las capturas utilizadas por RentApp para esta función se realiza en el dispositivo.

Estos servicios pueden procesar determinada información de acuerdo con sus propias políticas de privacidad y condiciones de servicio.

### 4. Intercambio de información

RentApp no vende ni comercializa los datos personales de sus usuarios.

La información solamente puede ser compartida o procesada por terceros cuando sea necesario para:

- Proporcionar los servicios técnicos indicados en esta Política.
- Gestionar y verificar suscripciones mediante Google Play.
- Autenticar cuentas mediante Firebase.
- Operar la infraestructura necesaria para el funcionamiento de RentApp.
- Cumplir una obligación legal o una solicitud válida de una autoridad competente.
- Proteger la seguridad de RentApp, sus usuarios o sus sistemas.

### 5. Datos de pantalla y OCR

RentApp utiliza funciones de captura de pantalla de Android exclusivamente cuando el usuario activa las funciones que requieren lectura de información visible en pantalla.

La Aplicación puede analizar temporalmente las imágenes capturadas para identificar información relacionada con ofertas de viaje, incluyendo precios, distancias y tiempos.

Las imágenes utilizadas durante este proceso:

- No se almacenan permanentemente por RentApp.
- No se utilizan para crear un historial visual de la pantalla.
- No se envían a servidores de RentApp para realizar el reconocimiento.
- No se venden ni se utilizan con fines publicitarios.

Los resultados obtenidos mediante OCR se utilizan para realizar los cálculos y funciones ofrecidos por la Aplicación.

### 6. Suscripciones y pagos

Las compras y suscripciones a RentApp Premium son procesadas por Google Play.

RentApp no recibe ni almacena directamente:

- Números de tarjetas de crédito.
- Datos bancarios.
- Códigos de seguridad de tarjetas.
- Credenciales utilizadas para realizar el pago.

RentApp recibe únicamente la información técnica necesaria para verificar que una compra o suscripción válida existe y determinar su estado.

Eliminar una cuenta de RentApp **no cancela automáticamente una suscripción contratada mediante Google Play**.

Si el usuario desea cancelar una suscripción activa, deberá hacerlo utilizando las herramientas de administración de suscripciones proporcionadas por Google Play.

### 7. Retención de datos

Mientras una cuenta de RentApp permanezca activa, podemos conservar la información necesaria para gestionar la cuenta, el dispositivo autorizado y el acceso Premium.

Cuando el usuario elimina su cuenta, RentApp elimina la información personal directamente asociada a dicha cuenta de sus sistemas activos, incluyendo la cuenta de Firebase Authentication y el documento principal de usuario almacenado en Firestore.

También se eliminan del dispositivo actual los datos locales gestionados por RentApp, incluyendo las preferencias de la Aplicación y las bases de datos locales utilizadas para historial y mantenimiento.

#### Prevención de fraude después de eliminar una cuenta

Para impedir el abuso de pruebas gratuitas, la reutilización indebida de compras y otros mecanismos destinados a evadir las restricciones del servicio, RentApp puede conservar determinados registros técnicos después de la eliminación de una cuenta.

Estos registros pueden incluir:

- El Android ID del dispositivo que utilizó una prueba gratuita.
- El hecho de que dicho dispositivo ya utilizó una prueba.
- Un hash criptográfico derivado de un purchase token que haya estado asociado a una cuenta eliminada.
- Marcas técnicas que indican que una cuenta fue desvinculada o eliminada.
- Fechas técnicas relacionadas con estas operaciones.

Cuando una cuenta es eliminada, RentApp elimina de estos registros los vínculos directos que utilizaba para asociarlos con la cuenta, como la dirección de correo electrónico y el UID de Firebase.

Estos registros técnicos se conservan exclusivamente para seguridad, prevención de fraude, protección del sistema de suscripciones y prevención de reutilización indebida de períodos de prueba o compras.

Actualmente estos registros antifraude no cuentan con un proceso automático de eliminación por antigüedad y pueden conservarse mientras sean necesarios para cumplir dichas finalidades.

### 8. Eliminación de cuenta

Los usuarios pueden eliminar su cuenta directamente desde RentApp.

La opción **"Eliminar cuenta"** se encuentra disponible tanto para usuarios con acceso Premium como para usuarios que se encuentren en la pantalla de suscripción.

Antes de ejecutar la eliminación, RentApp muestra una advertencia explicando las consecuencias de la operación.

Cuando el usuario confirma la eliminación:

- Se elimina su cuenta de Firebase Authentication.
- Se elimina el documento principal asociado a su cuenta.
- Se eliminan o desvinculan los datos personales asociados a los registros técnicos de prevención de fraude.
- Se eliminan las preferencias locales de RentApp del dispositivo.
- Se elimina el contenido de las bases de datos locales utilizadas por RentApp para historial y mantenimiento.
- Se cierra la sesión del usuario.

La eliminación de cuenta es irreversible.

Como se indica anteriormente, determinados registros técnicos mínimos pueden conservarse para prevenir fraude y abuso del servicio.

La eliminación de la cuenta de RentApp no cancela automáticamente una suscripción activa de Google Play.

### 9. Solicitudes de eliminación sin acceso a la Aplicación

Si no puede acceder a RentApp o ya no tiene la Aplicación instalada, puede solicitar la eliminación de su cuenta escribiendo a:

[oficialrentapp@gmail.com](mailto:oficialrentapp@gmail.com)

En el asunto del correo puede indicar:

**Solicitud de Eliminación de Cuenta**

Para identificar correctamente la cuenta, deberá indicar la dirección de correo electrónico utilizada para registrarse en RentApp.

Podremos solicitar información adicional únicamente cuando resulte necesaria para verificar que la solicitud corresponde al titular de la cuenta.

La eliminación estará sujeta a las mismas excepciones técnicas de prevención de fraude explicadas en esta Política.

### 10. Seguridad de la información

RentApp utiliza medidas técnicas destinadas a reducir el riesgo de acceso no autorizado, modificación o divulgación indebida de la información.

Entre estas medidas se incluyen:

- Autenticación mediante Firebase.
- Reglas de acceso de Firestore.
- Funciones de servidor para realizar operaciones sensibles.
- Verificación de suscripciones mediante los servidores de Google Play.
- Restricciones de acceso entre cuentas y dispositivos.
- Almacenamiento de determinados identificadores de compra mediante hashes para funciones de seguridad y prevención de fraude.

Sin embargo, ningún sistema informático, servicio en Internet o mecanismo de almacenamiento puede garantizar seguridad absoluta.

### 11. Copias de seguridad y datos locales

Android puede incluir determinadas bases de datos locales de RentApp dentro de los mecanismos de copia de seguridad proporcionados por el sistema operativo, dependiendo de la configuración del dispositivo y de la cuenta de Google del usuario.

RentApp limita las categorías de información incluidas en sus reglas de copia de seguridad y no incluye las preferencias de la Aplicación dentro de dichas copias.

Cuando una cuenta se elimina desde RentApp, la Aplicación elimina los datos locales de sus bases de datos en el dispositivo desde el cual se realiza la eliminación.

### 12. Privacidad infantil

RentApp Conductores está diseñada como una herramienta para conductores y usuarios adultos.

No está dirigida a menores de edad y no recopilamos intencionalmente información personal de menores.

Si detectamos que se ha creado una cuenta incumpliendo este requisito, podremos eliminarla.

- Acceso a sus datos personales.
- Corrección de información incorrecta.
- Eliminación de su cuenta y datos personales.
- Información sobre el tratamiento de sus datos.

Para realizar una consulta relacionada con sus datos personales puede escribir a:

[oficialrentapp@gmail.com](mailto:oficialrentapp@gmail.com)

Determinados datos técnicos podrán mantenerse cuando exista una finalidad legítima de seguridad y prevención de fraude, conforme se explica en esta Política.
